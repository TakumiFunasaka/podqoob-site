今日の服 プライバシーポリシー

最終更新日: 2026年11月25日

「今日の服」は、開発者本人だけが使う個人用のツールです。Google カレンダーの予定は、その日の服を選ぶためだけに使い、保存も第三者への提供もしません。

Google アカウントから取得する情報

利用者が許可した Google アカウントのカレンダーから、当日の予定（タイトル・時間・場所）を読み取ります。また、選んだ服を「今日の服」という予定としてカレンダーに書き込みます。求める権限は、予定の読み取りと書き込みだけです。

情報の使い方

  • 予定のタイトルと場所から、その日の場面（仕事・休日の外出・改まった場など）を判定します
  • 予定の場所から、天気を調べる地点を決めます
  • これ以外の目的には使いません。広告や解析には使いません

外部サービスへの送信

  • 国土地理院の住所検索：予定の場所に含まれる都道府県と市区町村の名前だけを送り、緯度・経度を調べます
  • Open-Meteo：緯度・経度を送り、天気予報を取得します
  • Anthropic（Claude API）：場面の種類、天気、服の候補を送り、1組を選ばせます。予定のタイトル・時間・場所は送りません

Google から取得した情報を、上記以外の第三者に提供・販売することはありません。

保存する情報

カレンダーの予定そのものは保存しません。保存するのは、日ごとに選んだ服の組み合わせ、場面の種類、最高気温の記録だけで、同じ組み合わせが続かないようにするために使います。

Google API の利用について

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

許可の取り消し

利用者は、Google アカウントの設定から、いつでも本ツールへの許可を取り消せます。

ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。
